## 위젯

- **id**: `w-next-token` / **데이터 계층**: L2 (사전계산 트레이스 재생 — 스트레치 L3는 Phase 1 제외 §8.2.2)
- **핵심 조작**: 문장 선택(큐레이션 8~12개) → 토큰 단위 스테퍼(◀ ▶) → 각 스텝에서 top-5 확률 막대 + 실제 다음 토큰 표시. **"내 예상 모드"**: 다음 토큰을 독자가 먼저 찍고 분포 공개
- **조작 가이드 3개** (§6의 2개 + 보완 1개):
  1. 확률이 한쪽으로 쏠리는 지점과 팽팽한 지점을 찾아보세요
  2. 내 예상과 모델의 1순위가 다른 지점을 찾아보세요
  3. "내 예상 모드"로 한 문장을 끝까지 진행해 보세요 — 몇 번이나 맞히나요?
- **데이터 (D2 결정 대기 — 권고: `EleutherAI/polyglot-ko-1.3b`)**:
  - `scripts/precompute/next_token.py`로 문장별·스텝별 top-k(k=8) 로그확률 추출, 표시용은 top-5
  - JSON `_meta`에 모델명·리비전·스크립트·생성일·시드 — 위젯 캡션에 노출(§3.3)

## 본문 흐름 (§6 준수 — 위젯 목격 → 설명 → 훅 회수)

1. 훅: 사람도 이미 하는 게임이라는 것 (1~2문단, 1-1의 nextHook "숫자만 보고 그게 어떻게 가능할까요?"를 받아서 시작)
2. 위젯: 문장을 고르고 한 스텝씩 진행, top-5 막대 관찰
3. 조작 가이드 3개
4. 설명: 언어모델의 정의(다음 토큰 확률), 자기회귀 생성(한 토큰씩 이어 붙여 다시 입력하는 루프), "확률 분포"가 출력의 전부라는 사실
5. 훅 회수: 대화·번역·코딩이 전부 이 게임의 변형임 — 위젯에서 본 쏠림/팽팽함이 곧 모델의 "판단"
