## 아하 모먼트 (독자가 챕터를 닫으며 얻는 한 문장)

모델의 눈에 '딸기'는 글자들이 아니라 숫자 몇 개다. 안이 안 보이니 셀 수 없다.

- 실측 주: o200k_base 기준 '딸기'는 3토큰(바이트 조각 2개 + '기')이다 — 본문 수치·예시는 위젯 실측값만 쓴다.

## 위젯

- **id**: `w-tokenizer` / **데이터 계층**: L1 (gpt-tokenizer 브라우저 실시간) / **구현 완료** (골든 테스트 10문장 스냅샷 + 바이트 폴백 + 무손실 분해 검증)
- **핵심 조작**: 문장 입력 → 색 블록 분해 목격 → 블록 탭(토큰 ID·바이트) → 한↔영 비교 모드 → 인코딩 전환(o200k_base 기본 / cl100k_base)
- **조작 가이드 3개** (§6 명세 그대로):
  1. "안녕하세요"와 "hello"를 넣고 토큰 수를 비교해 보세요
  2. 자기 이름을 넣어보세요
  3. "딸기"를 넣고 몇 조각인지 보세요

## 본문 흐름 (§6의 6단계 준수 — 위젯 목격 → 설명 → 훅 회수)

1. 파트 1 문지방 문장("ChatGPT가 하는 일은 단 하나, 글 조각들을 보고 다음에 올 조각을 맞히는 것…")으로 시작 + 'LLM' 어휘 다리(한 줄 번역 병기, §11.3) + 훅 구체화 (2~3문단)
2. 위젯: 아무 문장이나 넣어 쪼개보기
3. 조작 가이드 3개 (위젯 바로 아래)
4. 설명: 토큰 = 서브워드 조각, BPE의 직관(자주 붙어 나오는 조각을 병합 — sennrich2016), 글자·단어·토큰의 차이
5. 한국어의 비용: 같은 뜻이라도 한국어가 토큰을 더 쓴다 → API 요금·컨텍스트 소모로 직결 (petrov2023 근거 — 수치는 원문 확인 범위에서만 인용)
6. 훅 회수: 토큰 ID의 세계에는 'ㄹ'이 존재하지 않는다
