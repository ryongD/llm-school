> **게이트 1 v2.1** (2026-08-07) — 훅은 재성이 옵션 A로 확정.
> 근거: KICKOFF §6 파트 1 명세 + §8.2.3 위젯 스펙. D3 확정: FastText cc.ko.300.
> **v1 → v2 변경**: KICKOFF 원문 훅("왕 − 남자 + 여자 = ?")의 유추가 실측에서
> 재현되지 않음(단 '여왕'의 이웃은 왕비·왕·궁전으로 정상). 1-1의 딸기 사례와
> 같은 처리: 원 실험(영어, Mikolov 2013)의 역사로 서술하고, 한국어 실측 성공
> 사례를 위젯 버튼으로, 실패는 정직하게 다룬다.
> **v2 → v2.1 정정(CP2 치명 지적)**: 초기 실측의 변형형 필터(양방향 부분문자열)가
> '여왕'·'국왕'을 후보에서 원천 배제하고 있었음. 접두 일치 필터로 정정·재생성한
> 결과 왕 − 남자 + 여자 = **국왕(1위)**, 여왕은 **7위**(probe로 데이터에 기록) —
> 실패 결론은 유지되며 "계산이 도착한 곳이 여전히 '왕'"으로 서사가 강화됨.
> 채택 3건(도쿄·엄마·파리)은 필터 정정과 무관하게 불변.

## 위젯

- **id**: `w-embedding-map` / **데이터 계층**: L2 (사전계산 2D 좌표 + 유추 결과 재생)
- **핵심 조작**: 캔버스 산점도(단어 500~1,000개, 줌·팬) → 검색(단어 하이라이트 + 최근접 이웃 k=10 강조) → 유추 버튼 3~5개(사전계산 결과만 재생)
- **조작 가이드 3개** (§6 명세 그대로):

  2. 감정 단어들이 모인 대륙을 찾아보세요
  3. "아빠 − 남자 + 여자" 버튼을 눌러보세요 (v2.1: 왕 버튼은 아래 실측으로
     위젯에서 제외됐으므로 같은 성별 방향인 아빠 유추로 대체 — §6 원문과 다름)
- **정직성 장치** (§8.2.3):
  - 고정 캡션: "이 지도는 300차원을 2차원으로 눌러 담은 그림자입니다"
  - 이웃·유추는 **원 300차원 공간 기준 계산**임을 명시(2D 좌표 연산 아님)
  - 데이터 캡션: FastText cc.ko.300 · 생성 메타(_meta) 노출

## 데이터 (`scripts/precompute/embedding_map.py` — **생성 완료**, 3회 반복 확정)

- 소스: FastText `cc.ko.300.vec.gz` (CC-BY-SA 3.0) — 스트림 파싱
- 어휘: **시드 큐레이션 전용 21개 카테고리 538단어** (빈도 보충은 기능어
  오염으로 폐기 — 1차 실행에서 확인). 시드 목록은 스크립트 상단 상수
- 유추 실측 결과와 위젯 채택 (재성 확정 — 옵션 A):
  - ✅ 서울−한국+일본 = **도쿄**(1위) → 버튼 채택
  - ✅ 아빠−남자+여자 = **엄마**(1위) → 버튼 채택
  - ⚠️ 파리−프랑스+한국 = 뉴욕(1위)·**서울(2위)** → "유추의 한계" 정직
    사례로 버튼 채택
  - ❌ 왕−남자+여자 = 국왕(1위)·여왕(7위, probe 기록), 형−남자+여자 =
    동생(1위) → 위젯 제외. 왕 유추의 실패는 본문에서 정직하게 다룬다(훅
    회수 — "우리말 지도에서 이 산수는 절반만 됩니다")
- 산출: `data/traces/embeddings/map-2d.json` — 2D 좌표(UMAP 시드 고정) +
  원 공간 이웃 k=10 + 유추 top-3, 51KB (300KB 예산 내)

   토큰이 어떻게 의미를 갖게 될까요?"를 받음)
2. 위젯: 한국어 단어 지도 탐색

   이 지도가 학습으로 만들어진다는 예고(3부 복선)

   공간에서 가까운 것은 아님
6. 훅 회수: 유추 버튼 — 의미의 방향(성별·수도 관계)이 벡터 연산으로 드러남
