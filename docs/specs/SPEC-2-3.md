> 방향을 좌우하지 못한다.

> 상태와 **코사인 97~99%**를 유지한다. 즉 층은 갈아엎지 않고 조금씩 덧쓴다.
> 이것이 잔차연결(`LayerNorm(x + Sublayer(x))`)의 직접적 귀결이다.
> → **제안: 아하를 "층은 지우고 다시 쓰지 않는다. 조금씩 고쳐 쓴다"로 바꾼다.**

## 훅 질문 (KICKOFF §6 원문 유지 — 수치 검증 완료)

"트랜스포머 파라미터의 약 3분의 2는 어텐션이 아니라 이름도 밋밋한 'FFN'에
있다. 얘가 뭐길래?"

검증: 원 논문의 한 층에서 어텐션 파라미터는 $4d^2$(Q·K·V·출력 변환),
FFN은 $2 \cdot d \cdot d_{ff} = 8d^2$($d_{ff} = 4d$). 따라서
$8/(8+4) = 2/3$. 논문 수치로 확인: $d_{model}=512$, $d_{ff}=2048$
(Vaswani 2017 §3.3). 편향·LayerNorm은 무시한 근사임을 본문에 밝힌다.

## 아하 모먼트 (v2 — 실측 기반, 재성 확정 대상)

층은 지우고 다시 쓰지 않는다. 조금씩 고쳐 쓴다. 어텐션이 '정보 수집'이라면
FFN은 '개별 가공'이고, 잔차연결은 그 고침이 매번 원래 위에 더해지게 한다.

## 위젯

- **id**: `w-layer-flow` / **데이터 계층**: L2 (사전계산 재생)
- **핵심 조작**: 문장 선택 → 토큰 선택 → 층(0~24)을 따라가며 세 수치를
  꺾은선으로 표시. 직전 층 대비 유사도가 주인공
- **잔차 토글**: "지름길 있는 그림 / 없는 그림" 개념 대비(KICKOFF §6).
  없는 그림은 **모식도**이며 실측이 아님을 명시할 것
- **정직성 장치**:
  - 1층과 24층은 성격이 다르다는 안내(아래 실측 참조)
  - 24층은 최종 LayerNorm이 적용된 출력이라 길이가 급감함을 캡션에 명시
  - 데이터 캡션: polyglot-ko-1.3b · 생성 메타 노출

## 데이터 (`scripts/precompute/layer_flow.py` — 생성 완료, 24KB)

문장 6개(2-1·2-2와 동일 큐레이션) × 25개 상태(입력 임베딩 + 24층) ×

대비 코사인×100), `norm`(벡터 길이).
