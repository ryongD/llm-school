## 아하 모먼트 (v2 — 실측 기반)

헤드마다 맡은 관계가 다르다. 어떤 헤드는 내용과 무관하게 '바로 앞'만
보고(L2 헤드1 — 적중 90%), 어떤 헤드는 같은 낱말끼리 잇는다(L2 헤드15 —
'먹'→둘째 '배' 85%). 단, 이 분업이 모든 층에서 보이는 것은 아니다.

## 위젯 (신규 없음 — `w-attention` 확장 모드)

- **헤드 비교(그리드) 모드**: 같은 문장·같은 질의 토큰에 대해 16개 헤드 +
  평균의 top-1 대상을 카드 그리드로 나란히 비교. 카드 클릭 → 단일 보기로 이동
- **성격 배지**: 각 헤드의 답을 `바로 앞 / 첫 토큰 / 자기 자신 / 내용 연결`
  로 자동 분류해 배지 표시(질의가 1번 토큰이고 대상이 0번이면 '앞'과 '첫'이
  같아지므로 `앞·첫`로 중의 표기 — 측정 함정 회피)
- **다양성 카운터**: "16개 헤드가 서로 다른 답 N종" — 앞쪽 층의 분업과
  뒤쪽 층의 붕괴가 숫자 하나로 드러난다
- **정직성 장치**: 2-1과 동일(인과 방향·6층 수록·top-3) + 다양성 붕괴를
  숨기지 않음

## 실측 기록 (2026-08-07, polyglot-ko-1.3b@557e162, 트레이스 전수 분석)

헤드 성격 분포(8문장 전체, top-1 기준):

| 층 | 대표 헤드 | 성격 |
| --- | --- | --- |
| L2 | H01 | **바로 앞 91%** — 순수 인접성 헤드 (q≥2 한정 적중 75/83 = 90%) |
| L2 | H15 | 내용 연결 — 훅 문장에서 '타고'→'배' 94, '먹'→둘째 '배' 85 |
| L2 | H09 | 절 표지 지향 — 앞머리·'며'에 집중(내용 55%) |
| L0 | H08·H13·H15 | 자기 자신 45~47% |
| L5~L23 | 대부분 | 첫 토큰 53~91% (싱크) |

훅 문장의 답 다양성(16헤드 top-1의 서로 다른 대상 인덱스 수):

- L0 '먹' → **7종**, L2 '타고' → **5종**, L2 '먹' → 4종
- L11 '타고' → 2종, **L17 '타고' → 1종(전원 동일)**

측정 함정: 질의가 1번 토큰이면 '바로 앞'과 '첫 토큰'이 같은 자리라, 싱크
헤드도 '앞 9%'의 바닥값을 갖는다(문장당 1건 = 8/88). 분류·집계에서 이
경우를 중의로 처리해야 한다.

## 본문 흐름 (게이트 5 이후 집필 — §6 준수)

3. 조작 가이드 3개(초안): ① 한 토큰을 고르고 헤드 16개의 답을 한눈에 보세요
   ② '바로 앞'만 보는 담당자를 찾아보세요(L2 헤드1) ③ 층을 17로 올려
   보세요 — 답이 몇 종으로 줄어드나요?
4. 설명: Q·K·V 역할 분담("무엇을 찾고/무엇으로 검색되며/무엇을 건네줄지"),
   헤드 분할·결합
