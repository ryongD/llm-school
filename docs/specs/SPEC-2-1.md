## 아하 모먼트 (v2 — 인과 방향·실측 기반)

문맥 반영 = 뒤 단어가 앞 단어들을 가중치로 섞는 것. '먹'은 두 '배' 중
자기 '배'를 골라 강하게 쳐다본다(0.90 대 0.16) — 같은 글자를 어텐션이
문맥으로 구분한다.

## 위젯

- **id**: `w-attention` / **데이터 계층**: L2 (사전계산 어텐션 가중치 재생)
- **핵심 조작**: 문장 선택 → 토큰 탭 → 그 토큰이 앞 토큰들을 쳐다보는
  세기를 선(굵기/농도)으로 표시. 레이어·헤드 셀렉터. 기본 뷰는 큐레이션
  헤드(아래 실측의 스타 헤드)로 시작 — "아무 데나 눌렀더니 노이즈"를 방지
- **2-2 확장 모드**: 같은 문장의 여러 헤드 어텐션을 그리드로 비교
  (신규 위젯 아님 — 컴포넌트 재사용, KICKOFF §6 2-2)
- **정직성 장치**:
  - 인과 방향 명시: "각 토큰은 자신과 앞 토큰만 봅니다 (행별 합 1)"
  - 헤드 평균의 첫 토큰 쏠림을 숨기지 않고 셀렉터로 직접 보게 함
  - 24층 중 일부 층만 수록함을 캡션에 명시(용량 예산 §3.5)
  - 데이터 캡션: polyglot-ko-1.3b · 생성 메타(_meta) 노출
