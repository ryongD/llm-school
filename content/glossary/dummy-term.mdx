이 항목은 Phase 0 스캐폴딩에서 용어사전 파이프라인(스키마 검증 → 빌드 →
팝오버 → 상세 페이지 → 역링크)을 관통 검증하기 위한 더미다. 실제 용어
콘텐츠가 아니며, 어떤 사실 주장도 담지 않는다. 파트 1 파일럿(Phase 1)에서
실제 용어 15개가 들어올 때 삭제된다.

아래 문단은 용어사전 본문의 조판(300~800자 자유 형식, KICKOFF §4.3)을
확인하기 위한 채움 텍스트다. 위키형 상호 링크는 실제 용어가 둘 이상
생기는 Phase 1부터 동작을 확인한다.

참고문헌 표기는 렌더 검증용이다 — 본문이 해당 문헌의 내용을 인용하지 않는다.
