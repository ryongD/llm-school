## 본문 조판 검증

이 절은 본문 h2 제목, 문단 간격, <Term slug="dummy-term">더미 용어</Term>
팝오버, 그리고 시효성 수치 컴포넌트를 검증한다. 파이프라인 검증용 장난감
수치는 이렇게 렌더된다: <FactValue id="dummy.answer" />.

<Depth level="dev" hint="이 카드는 더 깊이 보고 싶을 때만 열면 됩니다">

개발자 레이어의 수식 조판 검증용 항등식이다 (장난감 예제 — 수학적 자명값,
모델 값 아님):

$$(a+b)^2 = a^2 + 2ab + b^2$$

코드 블록 하이라이트(Shiki, 토큰 기반 테마)도 함께 검증한다:

```python
def square(n: int) -> int:
    """더미 위젯 logic.ts와 같은 계산 — 골든 테스트 대상."""
    return n * n
```
